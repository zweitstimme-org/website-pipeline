# Official Berlin AGH names (Musterstimmzettel)

Berlin has no machine-readable Bewerberverzeichnis. Public official names are
the Landeswahlleiter **AGH Musterstimmzettel** PDFs (Direkt complete; lists
print only the first five names). BVV ballots are separate files — do not mix.

Generated by `code/parse_be_musterstimmzettel.py` from
[Wahllokalsuche](https://www.berlin.de/wahlen/wahlen/berliner-wahlen-2026/wahllokalsuche/artikel.1701445.php).

| File | Contents |
|------|----------|
| `direkt_from_musterstimmzettel.csv` | Every Direktkandidat on the AGH ballot |
| `list_tops.csv` | Positions 1–5 of each Landes-/Bezirksliste |
| `source_urls.json` | PDF URL pattern |

`list_tops.csv` is loaded by `code/listen_candidates.py` and **overwrites**
party-site harvest for those slots on every rebuild (so a BVV scrape cannot
replace the AGH Bezirksliste). Positions 6+ stay in `lists/*.csv`.

Re-parse (PDFs cached under `/tmp/be-agh-wk/`):

```
python3 code/parse_be_musterstimmzettel.py --download
python3 code/parse_be_musterstimmzettel.py --apply
```
